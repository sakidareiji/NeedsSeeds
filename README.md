# Needs Seeds

日常や業務の「困りごと」を投稿すると、AIが解析して解決策(アフィリエイト案件・一般アドバイス)を自動提示し、良質な投稿にはAI査定による**貢献スコア**(換金不可)が蓄積されるWebサービス。

> 困りごとの投稿は無償の愚痴ではなく、価値ある貢献である。その価値は現金ではなく、露出・信頼の可視化・将来の発言力という形で報われる。

## プロダクトの骨子

```
投稿 ──→ AI解析パイプライン(1回のLLM呼び出し)
          ├─ カテゴリ検証・サブタグ
          ├─ 商用ニーズ判定
          ├─ モデレーション(害悪は非公開/センシティブは商用提示なし)
          ├─ 解決策マッチング(マスタ) ──→ 「解決のヒント」表示(PR表記強制)
          ├─ 一般アドバイス生成(マッチなし時)─→ 全投稿に必ず何かが返る
          ├─ 品質査定 ──→ 貢献スコア付与(換金不可)/ 注目順ソートの係数
          └─ 追記促し(低品質投稿への聞き返し)

ユーザーの循環: 投稿 → 解決策が返る → わかる(共感) → 解決報告 → スコア・グレード
収益: ASP経由アフィリエイト(将来: 企業直販枠・データ提供)
```

## 技術スタック

- **Next.js**(App Router, TypeScript)— 投稿ページのSSRによるSEO
- **Supabase**(PostgreSQL, Auth, RLS)
- **Anthropic API**(claude-sonnet-4-6)— 解析パイプライン
- **Vercel** / **Tailwind CSS**

月間ランニングコスト目標: 5,000円以下。過剰なインフラ(専用ジョブワーカー、Redis等)は導入しない。

## ディレクトリ構成(方針)

```
/app          Next.js App Router
/components   UIコンポーネント(PR表記・注意書きはコンポーネントで強制)
/lib          Supabaseクライアント、LLM呼び出しの抽象化レイヤー
/prompts      AIパイプラインのプロンプト(コード変更なしで調整可能に)
/config       貢献スコアのマッピング、グレード閾値、ソート係数 等の設定
/docs         仕様書・設計ドキュメント
```

## 実装マイルストーン

1. **M1: 骨格** — 認証、投稿CRUD、カテゴリ、一覧・詳細(SSR)
2. **M2: 核** — AI解析パイプライン、解決策マスタ、自動提示、PR表記、クリック計測
3. **M3: 循環** — わかる、解決報告、貢献スコア・グレード、通知、実績
4. **M4: 運営** — 管理画面、種投稿インポート、モデレーション、通報
5. **M5: 公開準備** — SEO、静的ページ、レートリミット、デプロイ

各マイルストーン完了時に、動作確認可能な状態でコミットすること。受け入れ基準は仕様書 9章。

## 実装上の絶対ルール

- 金銭的なポイント・報酬・換金・交換の機能は**実装しない**(貢献スコアは換金不可の累積値としてのみ実装)
- アフィリエイトリンクの**PR表記**、一般アドバイスの**「専門的な助言ではない」注記**は、コンポーネントレベルで強制し、テストで担保する
- センシティブ判定(健康・借金・法律)の投稿には商用提示・一般アドバイスを出さない
- 投稿は物理削除しない(論理削除+退会時は個人識別情報の匿名化)
- プロンプト・スコア設定・ソート係数はハードコードせず `/prompts` `/config` に外出し
